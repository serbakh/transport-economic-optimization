# Основні результати другої симуляції

Завершена серія: 1836 сценаріїв, 18 360 навчальних і 9180 контрольних прогонів. Партія 10 000 т, постійний склад, добова норма 4000 т, 12 поєднань зовнішніх умов. [Методика й результати](../../docs/conditions-contract-ml-2026-11-07.md), [інструкція](../../docs/second-simulation-guide.md).

| Файл | Що містить |
|---|---|
| `plan.json` | Фактори, цілі, повтори, seed та правило допуску |
| `manifest.json` | Версії середовища, ставки, контрольні суми коду й результатів |
| `physical_runs.csv` | Фізичні й вартісні підсумки 27 540 прогонів |
| `daily.csv` | Тоннаж і виконання норми за періодами кожного прогону |
| `contexts/` | Окремі таблиці 12 поєднань зовнішніх умов |
| `split.json` | Розподіл складів між навчанням і відкладеною перевіркою |
| `heldout_model.joblib` | Модель перевірки на 31 повністю відкладеному складі |
| `final_model.joblib` | Остаточна модель, навчена на 18 360 прогонах |
| `predictions_1836.csv` | Готові прогнози та попередній допуск кожного сценарію |
| `control_predictions.csv` | Прогнози для контрольних повторів |
| `control_summary.csv` | Середні витрати, тривалість і число виконань норми в контролі |
| `decisions_by_conditions.csv` | Рекомендації й контрольний вибір для 12 пар умов |
| `evaluation.json` | Окремі метрики двох перевірок і результати вибору |
| `baseline_runs.csv`, `baseline_comparison.csv`, `comparison_summary.csv` | Порівняння з вихідною добовою моделлю |
| `verification.json` | Підсумок перевірки комплекту |

Контрольні суми первинних результатів залишено незмінними. Цей README додано пізніше як навігацію; він не входить до вихідного маніфесту експерименту. Повторно навчати моделі для читання таблиць або зміни ставок не потрібно. Прогноз, контрольне середнє та одиничний запис симуляції — різні величини.
