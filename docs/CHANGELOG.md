# Журнал змін проєкту

## 18.11.2026

Репозиторій зроблено публічним. Назва проєкту — «Економічний вибір ресурсів для перевалки». Уніфіковано назву й описи в документації та на GitHub. Попередній архів залишається закритим.

## Реорганізація 10–17.11.2026

Попередню папку `transport-economic-optimization` цілком збережено під назвою `transport-economic-optimization-archive-2026-11-10`. Поточний комплект займає початкове ім’я `transport-economic-optimization`.

До нього перенесено поточну серію `conditions_contract_ml_2026_11_07`, залежні програмні модулі, перевірки, вихідну модель для порівняння, робочі приклади, виробничі документи та демонстрацію. Код, моделі й числові результати завершеного експерименту збережено побітово. Переписано лише навігацію та перевірку структури під новий склад.

Не перенесено попередні датовані серії результатів, `historical/`, допоміжні аудиторські дані `data/`, старі пілотні запускні модулі й перевірки, застарілі плани та інструкції, локальні журнали, середовище `.venv`, налаштування редактора й каталог `.git`. Усі вони залишаються в повній архівній папці. Для роботи проєкту середовище створюється за короткою інструкцією.

Файли `src/vessel_cycle.py`, `src/static_contract_study.py` та `baseline/` є необхідними залежностями або джерелами відтворення поточного дослідження. Їх збережено; відсутність старих серій не означає видалення спільних функцій.

Приклад змінних ресурсів залишено лише як вхідний файл перевірок у `tests/fixtures/`. Перевірку історичного пілота виведення машин залишено разом із самим пілотом в архіві. Решта перевірок добової норми збережена; тест попереднього перегляду серії використовує поточний приклад.

Початкові контрольні суми перенесених файлів наведено у [журналі копіювання](migration-manifest-2026-11-10.json). Вони фіксують стан перед оновленням навігації. Контрольні суми дослідницького коду й результатів перевіряються за незміненим `manifest.json` основної серії.

Станом на 10.11.2026 це була лише локальна реорганізація; зміна GitHub тоді не виконувалася. Перенесення поточного комплекту на GitHub завершено окремим етапом 17.11.2026: попередній репозиторій перейменовано на `transport-economic-optimization-archive-2026-11-10`, а для поточного комплекту створено новий закритий `transport-economic-optimization`. [Звірка третього розділу та посилання](chapter3-verification-2026-11-17.md). Повторного навчання й основного експерименту не проводили.

## Виконані перевірки

Пройдено 43 модульні перевірки. Перевірено 49 контрольних сум коду й матеріалів, локальні посилання, 1836 прогнозів і вісім відтворень демонстрації. Окремою перевіркою стандартними засобами Python перевірено 27 540 прогонів та 94 429 добових записів: баланс 10 000 т, виконання норми за повними добами, відновлення витрат і 12 рекомендацій. Програми перевірки використали наявне середовище Python; до поточного комплекту встановлені бібліотеки не копіювалися.

Штатна поглиблена перевірка `verify_conditions_study.py` потребує NumPy і pandas, яких у використаному середовищі немає. Тому її повний запуск під час очищення не завершився; контрольні суми, основні таблиці та рішення перевірено окремо без цих бібліотек. Збережені JOBLIB-моделі не завантажувалися й не перенавчалися.
