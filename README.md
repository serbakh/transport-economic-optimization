# Економічний вибір ресурсів для перевалки

Чистий робочий проєкт третього розділу. Партія — 10 000 т, комплектація постійна; критерій — найменші прогнозні витрати серед варіантів, допущених за нормою не менше 4000 т у кожному повному 24-годинному періоді. Останній неповний період завершує залишок.

[Демонстраційний сайт](https://serbakh.github.io/transport-terminal-demo/) · [відкритий код сайту](https://github.com/serbakh/transport-terminal-demo) · [архів попереднього проєкту](https://github.com/serbakh/transport-economic-optimization-archive-2026-11-10).

Цей закритий репозиторій містить чистий комплект із новою історією Git. Повна попередня історія збережена в окремому закритому архіві. [Звірка з редакцією третього розділу від 17.11.2026](docs/chapter3-verification-2026-11-17.md); зафіксована версія комплекту — тег `chapter3-2026-11-17`. Повний текст дисертації до репозиторію не включено.

## Склад

| Каталог | Призначення |
|---|---|
| `src/` | Поточна симуляція, перевірка норми, калькуляція та експеримент |
| `results/conditions_contract_ml_2026_11_07/` | Єдина збережена дослідницька серія: 1836 сценаріїв, 27 540 прогонів |
| `examples/` | Поточний приклад, технологічні умови й ставки |
| `tests/`, `tools/` | Перевірки, читання результатів та складання демонстрації |
| `baseline/` | Зафіксована вихідна модель для відтворення порівняння |
| `demo/` | Інтерфейс і підготовлені дані; збережено також добовий режим порівняння |
| `docs/` | Інструкції, протокол і походження матеріалів |

`src/vessel_cycle.py` залишено, оскільки поточний симулятор використовує його функції календарних операцій. `src/static_contract_study.py` містить спільну калькуляцію та функції основної серії, хоча також має точку запуску попереднього експерименту. Ці файли збережено без змін, щоб не порушити контрольні суми дослідження. Попередні результати цих експериментів до чистого комплекту не включено.

## Перевірка

Після встановлення залежностей за інструкцією:

```powershell
python tools/run_tests.py
python tools/verify_repository.py
python tools/verify_conditions_study.py --output results/conditions_contract_ml_2026_11_07
node tools/check_integrated_demo.cjs
```

Фізичні показники відокремлено від ставок. Результати отримано в модельному експерименті; окупність впровадження й відповідність реальним замовленням окремо не встановлені.
