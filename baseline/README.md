# Вихідна реалізація для порівняння

Цей каталог містить незмінений код із комміту `b8e2dfdadc81ca2e122bc8881a8db9d3a8e773e1` репозиторію `serbakh/transport-digital-twin`.

## Склад

- `src/simulation/digital_twin.py` — добова симуляція та генерація сценаріїв.
- `src/ml/train_model.py` — навчання й оцінювання моделей ML.
- `src/ml/recommend_resources.py` — рекомендації ресурсів за прогнозом тоннажу.
- `src/analysis/plot_results.py` — графіки експерименту.
- `requirements.txt` — оригінальні версії залежностей.
- `SHA256SUMS.txt` — контрольні суми перенесених файлів.

## Умови використання

Код збережено як основу для порівняння. Він ще не реалізує симуляцію до завершення партії 10 000 т та не оптимізує грошові витрати. Модулі мають виконуваний код верхнього рівня: імпорт може запускати розрахунки або читання файлів. Перед використанням як бібліотеки нова реалізація потребує окремої точки запуску.

Вихідні шляхи даних відносні до поточної робочої папки. Для відтворення старого експерименту запускати скрипти слід з каталогу `baseline`, у послідовності: симуляція, навчання, рекомендації, графіки. CSV, готові моделі та PNG сюди не копіювалися; їх потрібно генерувати або брати з точної вихідної версії. Повторне генерування без фіксованого випадкового seed не відтворює старий набір побітово.

Попередній аудит виявив відмінність версій: оригінальний список залежностей указує scikit-learn 1.7.0, тоді як збережені таблиці й моделі відтворювалися з 1.9.0. Тому цей requirements.txt збережено як історичний файл; він не є остаточним середовищем нового дослідження. Перевірені залежності нового проєкту визначимо окремо.

На цьому етапі перевіряється точність перенесення файлів, а не повторюється повний експеримент. Виправлення моделі та нові результати слід оформляти окремими змінами, зберігаючи можливість порівняння з цією основою.
